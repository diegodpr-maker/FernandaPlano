# FernandaPlano

Plano de estudos para residência médica da Fernanda.

## Primeira publicação

A versão inicial preserva o HTML original. Publique a raiz deste repositório no GitHub Pages (branch main).

Os registros são salvos no navegador e não são enviados ao GitHub. Para transferir dados do arquivo local para o site, exporte um backup no sistema original e importe no endereço publicado.

## Próxima etapa

Migrar a interface para React, criar servidor Node e imagem Docker, e completar o PWA com manifesto, ícones e service worker. GitHub Pages hospeda arquivos estáticos; um servidor Node em Docker precisa de hospedagem compatível com containers.
